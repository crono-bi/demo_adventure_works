# scratch

This folder is for test and exploration queries that are not part of the project: checking source data, trying out a change to a model, or a `.sql` script that runs several loads at once. Use it instead of leaving files like `test.sql` or `delete_me.sql` in the project root.

Nothing here is versioned: the whole project goes into Git except this folder. Do not keep anything here that the project needs to work. If a test turns out to be useful, move it to `procedures/` or `jobs/`.
